# bm-questions

Pages de questions à choix multiples pour Bahia Mala.

**Ce dépôt est public.** Il n'héberge que des formulaires : chaque lot a sa
propre adresse, aucune donnée n'y est stockée, les réponses partent par mail
depuis le téléphone de la personne qui répond.

Ce qui n'y va jamais : les plans de contenu, les revues internes, les chiffres
de la marque, les conditions revendeur. Ces documents se transmettent en pièce
jointe, pas par une adresse publique.
